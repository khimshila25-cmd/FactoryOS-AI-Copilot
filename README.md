# FactoryOS AI Operations Copilot

FactoryOS AI Operations Copilot is an AI Agentic RAG platform for manufacturing operations.

The system helps factory owners and operations teams interact with production data, SOPs, supplier reports, and operational documents using natural language.

## Features

- Document Intelligence
- Manufacturing Knowledge Assistant
- Supplier Risk Analysis
- Operations Copilot
- AI-Powered Recommendations
- Retrieval-Augmented Generation (RAG)

## Tech Stack

- Python
- Streamlit
- LangChain
- FAISS
- HuggingFace Embeddings
- Groq LLM
